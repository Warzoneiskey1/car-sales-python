# Car Sales Analysis – Jeffrey Godwin

**Live Project** | Python (Pandas + Matplotlib + Seaborn)

**Link to notebook** → [analysis.ipynb](analysis.ipynb)

### What this project does
- Cleans 8,000+ rows of raw car sales data (removes duplicates, fixes formats)
- Calculates revenue and profit
- Finds top-selling models and seasonal trends
- Creates clean charts (bar chart of top models, monthly sales trend)

### Tools used
- Python
- Pandas – cleaning & analysis
- Matplotlib & Seaborn – visualizations

### How to run
1. Download the repo
2. Put your CSV file and name it `car_sales.csv`
3. Open `analysis.ipynb` in Google Colab or Jupyter
4. Run all cells
